Secure Budget Dashboard

Security-first starter for personal budgeting with Plaid Link.

Security defaults

  • No bank credentials are entered in this app (Plaid Link only).
  • Plaid secrets stay server-side and are loaded from environment variables.
  • Access tokens are encrypted in memory and never written to disk.
  • No raw transaction or account/routing numbers are persisted by this app.
